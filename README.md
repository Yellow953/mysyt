# mysyt

Mr. Yellow Scarf: agentic YouTube channel workspace. Start with CLAUDE.md and START-HERE.md.

Not in git (recreate on a new device): `.venv/` (run the `setup` skill), `remotion/node_modules/` (`npm install` in remotion/), `secrets/` (YouTube OAuth files), rendered media in `videos/` and `remotion/public/`, music in `assets/music/`.
