## C. Pipeline facts (tools, costs, limits)
- Higgsfield images per image: gpt_image_2 0.5 (low quality, 752x1344; keeps the character via the element tag), seedream 1, nano_banana_2 1.5, nano_banana_pro 2. Plus plan: max 8 concurrent image jobs; a 12-image batch call can time out after creating 8 jobs (check show_generations before resubmitting).
- Voice clips (ElevenLabs via Higgsfield): ~0.15-0.6 credit each; send 8 at a time (429 rate limit beyond ~10). A 12-scene Short with ~16 clips and a thumbnail costs ~10 credits.
- Local tools: `scripts/shared/build_voice.py` (clips + performance.json → voice.wav + segments.json), `scripts/shared/captions.py` (uses segments.json; whisper alignment failed on long pauses), `scripts/short-form/assemble.py` (Pillow frames → ffmpeg; Homebrew ffmpeg has no libass/drawtext), `scripts/short-form/thumbnail.py`. Kokoro (`scripts/short-form/tts.py`, `pace.py`) is only a free offline fallback for timing tests.
- Voice 429s: expect 1-2 clips per batch to rate-limit; resubmit only those. scenes.json supports a "moves" array (several camera moves per scene, assemble.py) for scenes over ~6 s. Trimming pauses in performance.json + rebuild_voice saves ~0.5-2 s with no re-recording. Real cost of a 10-12 scene Short: ~8-9 credits. Script-writer subagents under-estimate runtime: use ~2.2 words/s + pauses.
- YouTube upload API (2026-10-30): `scripts/short-form/youtube_upload.py` works; unaudited project = private only; OAuth in Testing mode = token expires every 7 days (re-run `auth`); consent-screen logo and Publish both trigger verification/URL requirements, so skip them.
- YouTube's transcript panel and caption endpoints are blocked for automation: use watch-with-subtitles (captions read off the muted video at 4-6x), never download videos.
- Facts in the haiku-made reference analysis ("1963 researcher", "2008 study", "90,000 hours") were unverified; always verify independently.
