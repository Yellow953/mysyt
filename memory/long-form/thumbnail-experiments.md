# Thumbnail and character experiments (long-form)
Rules: one change per pair; similar topics/pillar; record, don't assume causation; small samples = TENTATIVE; observation, hypothesis and verified kept separate. Use Studio's thumbnail test feature if available (check), otherwise paired videos.
Track per video: composition, expression, adult character present (m/f/none), tier (0/1/2), text vs no text, emotional concept, pillar.
Metrics: impressions, CTR, first-30s retention, avg view duration, watch time, subs, traffic sources.
