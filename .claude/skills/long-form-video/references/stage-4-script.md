# Stage 4: Script
1. `lf-scriptwriter` -> `script.md` (narration with direction tags and pauses, scene visuals, on-screen text, SFX, music, transitions, retention notes, CTA; ~5 min ≈ 550-650 words).
2. `lf-critic` -> `review.md` (verdict, top problems, fixes). If REVISE: send fixes back to the scriptwriter (max 2 rounds), then re-review.
3. Optionally `lf-fact-checker` re-checks every factual line against `research.md`.
4. Present to Joe: the script path, the critic's verdict and what you changed or declined and why, remaining weak spots. STOP. No credits. Update state.json (gate `4_script`).
